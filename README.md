**Training App API**

Профессиональная платформа для управления тренировочными планами, взаимодействия тренеров и клиентов, а также отслеживания прогресса тренировок.

**Основные возможности:**

-Управление планами: Создание тренировочных планов с детализацией по упражнениям (подходы, повторения, вес, отдых).

-Ролевая модель: Четкое разделение прав доступа (Тренер / Клиент). Только тренеры могут создавать и назначать планы.

-Система уведомлений: Автоматические уведомления о новых планах, тренировках и отзывах.

-Отзывы и рейтинги: Возможность оценивать тренировочные планы и работу тренеров.

-Отслеживание результатов: Фиксация выполнения конкретных упражнений и завершения тренировочных сессий.

-Автоматизация: Фоновые задачи через Celery (рассылки, очистка данных).

-API Документация: Интерактивная документация Swagger и Redoc.


**Технологический стек:**

Backend: Python 3.12+, Django 5.1+, Django REST Framework

Database: PostgreSQL

Task Queue: Celery + Redis

Auth: JWT (Simple JWT)

Documentation: Drf-spectacular (Swagger UI)

Containerization: Docker & Docker Compose
